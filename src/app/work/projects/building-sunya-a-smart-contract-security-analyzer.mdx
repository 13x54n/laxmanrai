## Overview

Sunya began as a full-stack dashboard for Starknet and EVM smart contract security analysis with ML models, gasless meta-tx, and API integrations. The new v1 version streamlines to a cross-platform CLI tool focused on Slither-powered EVM static analysis—install once, run `sunya scan` anywhere to detect vulnerabilities automatically.

## Key Features

- **One-Command EVM Analysis**: `sunya scan` auto-detects Solidity files in `./contracts` or `./src`, runs Slither—no config needed for basic use.
- **Frictionless Install**: Curl/PowerShell scripts handle Slither/Node/Python dependencies across Linux, macOS, Windows; auto-updates tooling.
- **Configurable Scans**: `sunya.config.json` for custom directories (`./src` for Foundry), output formats (table/JSON), and env vars like `SUNYA_CONTRACTS_DIR`.
- **CLI Commands**: `sunya install` (updates Slither), `sunya uninstall [-y]`, `sunya --help`—simple, scriptable for CI/CD pipelines.
- **Builds on Original**: Retains Slither core from dashboard version; drops Starknet/ML/dashboard for lightweight, local-first audits (80% faster claimed).
- **Cross-Platform**: Bash for Unix, PowerShell for Windows; adds PATH setup for instant `sunya` access post-install.

## Technologies Used

- **Node.js/Bash/PowerShell**: Cross-platform installer and CLI runtime.
- **Slither**: Core EVM static vulnerability detector (auto-installed).
- **JSON Config**: Simple project-level customization.
- **Inherited from v0**: Core Slither integration; simplified from Vite/React, Scarb, ArgentX, IPFS, Voyager/Etherscan APIs.

## Installation Examples

**Linux/macOS:**

```bash
curl -sSL https://raw.githubusercontent.com/13x54n/sunya-v1/main/package/bin/install | sh
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc  # or ~/.bashrc
sunya scan  # Ready!
```

**Windows (PowerShell):**

```powershell
irm https://raw.githubusercontent.com/13x54n/sunya-v1/main/package/bin/install.ps1 | iex
sunya scan  # Restart terminal first
```

**Foundry Project Example:**

```bash
forge init my-token && cd my-token
sunya scan  # Scans ./src/*.sol, outputs Slither table
```

**Custom Config (`sunya.config.json`):**

```json
{
  "contractsDir": "./src",
  "output": { "format": "table" }
}
```

## Challenges and Learnings

Key evolution: Simplified cross-chain dashboard to portable CLI amid resource constraints and user feedback favoring local tools over web apps. Mastered platform-specific installers (Windows PowerShell quirks, PATH persistence) while preserving Slither's power. Learned CLI tools excel for devs—enabling CI integration vs. original's dApp friction.

## Outcome

**From StarkHack Winner** (Voyager/Herodotus prizes) to production CLI: Delivers instant Slither audits anywhere, no setup friction. Battle-tested for Foundry/Hardhat projects; open-source at github.com/13x54n/sunya-v1 for community contributions. Powers faster, local-first smart contract security.
